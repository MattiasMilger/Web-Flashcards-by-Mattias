Help & Info

About

Web Flashcards by Mattias

A browser-based flashcard study app. Create decks, add cards with optional notes, and study using spaced repetition - all from your browser with no server required.

Features

Deck Management
  • Create decks - give each deck a name and start adding cards.
  • Premade decks - in Manage Decks, tap Browse Premade Decks to add ready-made vocabulary decks (Spanish, French, German, Italian, Portuguese, Polish, Ukrainian, Japanese, Mandarin, Korean, Indonesian, Swedish, Turkish).
  • Rename deck - select a deck in Manage Decks and click Rename to give it a new name.
  • Import/Export - save decks as .json or .txt files and reload them later.
  • Import from text - paste or load cards in "Word - Translation" or tab-separated (Anki export) format, one per line.
Card Notes
  • Optional notes - add explanatory notes, mnemonics, or usage examples to any card in the Card Editor.
  • Revealed on answer - notes remain hidden when viewing the question and appear only after you press Show Answer during review.
  • Clean compatibility - notes are fully optional and supported in both JSON and text backups without altering existing deck saves.
Spaced Repetition (SM-2)
  • Cards are scheduled based on how well you know them.
  • Again (<10m) - failed, review again soon.
  • Hard (1–2d) - struggled, short interval.
  • Good (3–7d) - normal, standard interval.
  • Easy (7d+) - easy, long interval.
  • Only new cards and cards due today (or overdue) appear in your session.
Accumulate Daily Goal
  • When set to Yes, any cards you didn't study on a given day carry over and are added to the next day's goal.
  • For example, with a daily goal of 8 and no cards studied for three days, you'll have 24 cards queued on day four.
  • When set to No (default), each day starts fresh with exactly the daily goal regardless of missed days.
  • Turning this setting off clears any currently accumulated cards.
Session Controls
  • Daily Goal - set how many cards to study per day in Settings.
  • Study More - extend the session when daily goal is reached.
  • Undo Last Rating - undo your most recent card rating.
  • Click the card - copies the displayed text to clipboard.
Data Config
  • Export Config - download a single full backup with all decks and settings.
  • Import Config - restore your entire collection from a JSON backup.
  • Reset Config - restore defaults with typed confirmation in the Danger Zone.
Appearance
  • Dark / Light mode - toggle theme with the button.
  • Responsive - works on desktop and mobile.

Keyboard Shortcuts

  • Space / Enter - show answer (when viewing card front).
  • 1 - Again
  • 2 - Hard
  • 3 - Good
  • 4 - Easy
  • Escape - close any open modal.

Technical Notes

All data is stored in your browser's localStorage. Nothing is sent to a server. Clearing browser data will erase your decks - export them first as a backup.
